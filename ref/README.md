## กติกา

- เอกสารใน `ref/` **ไม่ใช่ข้อผูกพัน** — สิ่งที่บังคับใช้จริงอยู่ใน [`../decisions/`](../decisions/)
  ถ้า `ref/` กับ ADR ขัดกัน ให้ยึด ADR แล้วเปิด issue
- อยากเพิ่มเอกสารต้นทางใหม่ → วางไฟล์ + เพิ่มแถวในตารางข้างบน + ระบุที่มาและวันที่ดึง
- ห้ามแก้เนื้อหาไฟล์ที่ดึงมา (แก้ = ไม่ใช่ต้นฉบับอีกต่อไป)
